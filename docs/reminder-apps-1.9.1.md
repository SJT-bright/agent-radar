# 1.9.1 应用提醒选择

2026-10-15。macOS 与 Windows 增加独立「设置 → 提醒」页面，支持应用复选框、搜索、全选与全不选。点击保存后同时控制提醒弹窗与音效，选择持久保存。

旧版设置默认继续提醒全部应用。全选包括后来发现的应用；仅勾选模式中，新应用默认不提醒。取消应用会清理该应用当前及排队提醒，重新选择不会补发旧完成提醒。临时离线应用保留选择。涉及多个应用的目录冲突，只要其中一个应用在提醒范围内仍可提示。

提醒选择与监督、持续关照及自动发送授权分开，保存提醒范围保留原有 FIFO 操作队列。
