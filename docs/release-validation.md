# 1.8.18 发布验证

发布版本：1.8.18（build 72），2026-10-09，Apple Silicon / macOS 13+。

公开源码保留原公开仓库历史。本机验证文档、数据库、运行日志及真实会话发送探针未进入公开副本；测试里的个人路径与真实会话 ID 使用通用数据替换。生产 Swift、Python 与界面操作实现保持与本机对应版本一致。

## 已完成的检查

- 公开副本 `scripts/test.sh` 全部通过：258 项 Python 测试、全部 Swift 检查及 37 项硬件输入检查。覆盖长日志回溯、未知状态、轮次去重、监督授权、提醒队列、设置草稿、目录冲突、慢采集来源隔离及过期状态。
- 最后菜单事件坐标与键盘焦点修正后，重新构建完整应用并补跑 33 项悬停状态和 17 项菜单布局检查。
- 完整发布构建使用已有 `AgentRadar Local` 签名身份，`codesign --verify --deep --strict` 通过。签名身份有效不等于目标机器的辅助功能权限已生效；安装后需通过浮窗“查询”实际复查。
- 应用与源码 ZIP 通过结构及哈希检查；GitHub 上传文件的 SHA-256 与本地一致。下载页同时提供 `SHA256SUMS`。

## 验证范围

本版的会话读取、菜单交互和桌面表现按对应本机验证记录复查。隔离组件验证与正式桌面查询分别留存，测试通过不替代所有目标应用、所有新轮次的实际发送结果。此次发布没有发送聊天测试消息。

当前识别机制主要读取本地结构化数据与 AX 控件。Gemini 和 Antigravity 的应用发现不代表读取全部后台对话或已支持自动续接。真实硬件鼠标的悬停手感也不能仅由远程指针事件或程序状态测试证明。

本次 GitHub 发布不要求替换或重启本机正在运行的应用；本机安装由独立的桌面更新流程处理。
