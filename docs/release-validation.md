# 1.8.20 发布验证

版本：1.8.20/build74，2026-10-11，Apple Silicon / macOS 13+。

本版将跨对话桌面操作改为先进先出，移除自动插队。原有身份、项目、轮次、草稿回读、真实键鼠避让和同轮防重复规则保留。详见 [顺序队列验证](fifo-validation.md) 与 [识别机制](recognition.md)。

## 检查

- 258 项 Python 测试、全套 Swift 检查及 37 项硬件输入检查通过。
- 新增 18 项三会话顺序模拟，覆盖延迟队首、手动请求、定位重试、响应确认、超时、取消、陈旧证据与窗口操作互斥。2160 个唯一轮次的 12 小时模拟逐条确认发送响应。模拟桥不操作真实聊天。
- 公开源码副本独立构建与回归；公开内容排除本机偏好、数据库、会话日志和真实发送探针。应用包使用已有有效 AgentRadar Local 身份签名，严格校验通过。
- 隔离设置窗口已实际打开，展示顺序队列说明，不再提供自动插队开关。预览未启动监控，关闭后测试偏好已清理。
- 下载页提供应用 ZIP、源码 ZIP 和 SHA256SUMS；上传后核对服务端与回下载哈希。

## 范围

经用户确认，1.8.20/build74 已正式安装并重启。315 个文件哈希与候选一致，严格签名通过；正式浮窗和实际窗口访问、输入组件查询通过，状态记录为 fifo、自动插队关闭。原监督范围、执行设置与防重复记录保留。构建、签名、队列模拟和设置预览不能证明实际新轮次自动发送。本次没有发送聊天测试消息；其他设备安装后仍需通过浮窗“查询”复核窗口访问与输入组件，真实发送须另有新轮次回执。
