# 1.8.23 发布验证

版本：1.8.23/build77，2026-10-11，Apple Silicon / macOS 13+。

本版修复 Codex 发送前长日志冷读漏恢复，并加强路由身份和发送时间核验；自动恢复提示词与设置删除同时修正。严格 FIFO、持久防重复、草稿回读、硬件输入避让和超时只读观察保留。[审查及建议](audit-20261011.md)

- 私有与公开源码各通过 295 项 Python 及全套 Swift 检查，包括 22 项 FIFO、92 项提示词草稿、5102 项监督模拟与 37 项硬件输入检查。12 小时模拟为 2160 个唯一发送轮次，每次都核对新轮晚于对应发送。
- 公开源码独立编译并严格签名；依赖复用已有本地 PyObjC 模块，放入隔离 venv，不更改全局环境，不上传依赖安装目录。公开构建的 312 个资源文件与正式版一致。
- 原目标实际日志约 923 MiB。新版首次按目标核验即找到真实运行轮次；正式安装包只读检查 identity=true、input_count=1、busy=true、attempted=false，未导航或输入。
- 隔离设置使用生产界面和独立偏好，未启动监控，发送桥禁用。清空已存专属续接/恢复文字、保存、关闭重开后为空均实际检查通过。
- 正式入口 `/Applications/任务雷达.app` 的 315 个文件与候选一致，已有 AgentRadar Local 签名严格校验通过。正式展开、收起和“查询”实查窗口访问、输入组件均通过；自动发送及监督设置、Journal 保留。只重启雷达。
- GitHub 提供应用 ZIP、源码 ZIP、SHA256SUMS，发布后核对服务端与回下载哈希；应用 ZIP 解包还须逐文件对照正式安装版。

本次观察到 1.8.22 一次真实已授权 Codex 自动发送与同会话新轮确认；它不是最初目标，也不是 1.8.23 的真实发送验收。原目标正在运行，新版回执为 already_running；没有向它发送测试文字。未知或超出预算仍拒发。布局、系统权限和设备差异仍须在安装后检查；完整审查的剩余事项见上述报告。

## 历史：1.8.20 发布验证

版本：1.8.20/build74，2026-10-11，Apple Silicon / macOS 13+。

本版将跨对话桌面操作改为先进先出，移除自动插队。原有身份、项目、轮次、草稿回读、真实键鼠避让和同轮防重复规则保留。详见 [顺序队列验证](fifo-validation.md) 与 [识别机制](recognition.md)。

## 检查

- 258 项 Python 测试、全套 Swift 检查及 37 项硬件输入检查通过。
- 新增 18 项三会话顺序模拟，覆盖延迟队首、手动请求、定位重试、响应确认、超时、取消、陈旧证据与窗口操作互斥。2160 个唯一轮次的 12 小时模拟逐条确认发送响应。模拟桥不操作真实聊天。
- 公开源码副本独立构建与回归；公开内容排除本机偏好、数据库、会话日志和真实发送探针。应用包使用已有有效 AgentRadar Local 身份签名，严格校验通过。
- 隔离设置窗口已实际打开，展示顺序队列说明，不再提供自动插队开关。预览未启动监控，关闭后测试偏好已清理。
- 下载页提供应用 ZIP、源码 ZIP 和 SHA256SUMS；上传后核对服务端与回下载哈希。
