# 1.8.19 发布验证

发布版本：1.8.19（build 73），2026-10-09，Apple Silicon / macOS 13+。

本版在 1.8.18 已发布内容上加入浮窗顶部锚点保存，修复展开状态退出后重启下移。公开源码沿用公开仓库历史，排除本机记录、数据库与真实会话探针；测试里的个人路径和真实会话 ID 已替换为通用数据。

## 检查

- 公开副本完整构建与 `scripts/test.sh` 通过：258 项 Python 测试、全部 Swift 检查及 37 项硬件输入检查。包含 33 项悬停状态、17 项菜单布局，以及轮次、授权、提醒、设置、慢来源隔离和过期降级检查。
- 对应生产实现已在本机 1.8.18/build72 正式应用完成桌面复查。1.8.19 发行包保留这份原生程序与运行资源，仅更新版本信息并以原有 `AgentRadar Local` 身份重签；原生代码段和运行资源与对应正式版一致。公开源码另做独立完整构建。
- 发布包严格签名校验通过。应用 ZIP 和源码 ZIP 结构及内容核对通过；GitHub 服务端与回下载 SHA-256 和本地文件一致。下载页提供 `SHA256SUMS`。

## 范围

本次上传未替换或重启本机正式应用，1.8.19 发行包本身未作为正式安装版启动；桌面结果来自相同生产实现的 1.8.18。构建、单元测试、签名、桌面读取和真实发送分别记录，不能相互代替。此次发布没有发送聊天测试消息，所有目标应用的新轮次实际自动续接仍需分别验证。

当前识别主要读取本地结构化数据与 AX 控件。Gemini 和 Antigravity 的应用发现不代表读取全部后台对话或已支持自动续接。真实硬件鼠标的悬停手感不能仅由远程指针或程序状态测试证明。辅助功能授权需要安装后通过浮窗“查询”实际复查。
