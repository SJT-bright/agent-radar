## 打开

## 夜间常亮与状态可靠性（1.6.7）

菜单「夜间常亮（防休眠）」可以随时开关，选择会保存。它向系统申请防空闲系统休眠和防显示器休眠，每分钟及唤醒后复核；关闭或退出应用释放。它不模拟键鼠，不修改密码或屏保设置，不能阻止独立屏保自动锁定、主动锁屏、合盖或低电量关机。锁屏设置由用户自行调整。

小胶囊尚未取得首轮数据、或采集超过 15 秒未更新时显示「…」，不把缺数据显示成 0。Codex 按 turn ID 对齐开始/结束事件，首次读取最多 8 MiB；尚未找到起点时，后续每次采集再回溯一块（每块最多 8 MiB），只缓存至多 4096 条生命周期与请求答复元数据。找到起点后转为增量读取，旧轮中断不覆盖新轮。回溯期间、超过元数据上限或没有有效事件时保持待确认，不从文件更新时间推断运行状态。

ZCode 任务索引用于标题、工作区和任务身份，`~/.zcode/cli/db/db.sqlite` 中的 `turn_usage` 用于真实轮次。工作区与会话 ID 双重核对；进行中再读模型/工具时间，完成轮次直接用结束时间，避免反复读取历史。单次查询超过 1 秒会降级并说明下轮重试，不伪报完成。旧版本没有轮次表时才使用有界日志兼容路径。

## 时间与中断

- **本轮**：使用明确的轮次开始事件或状态表时间。Codex、AutoClaw、WorkBuddy 两个版本、Qoder 的轮次投影及 Grok 的生命周期事件可提供这一时间；任务完成/中断后固定在结束时间。
- **已确认**：仅知道进程已退出、缺少确切结束时间时，显示到最后确认事件为止的时长。
- **已观察**：应用没有暴露可靠开始时间时，从雷达本次首次检测到活动开始显示经过时间，不冒充完整运行时长；重新启动雷达后重新观察。
- **已中断**：明确的失败、取消、终止、超时事件，或 AutoClaw 遗留锁所指的执行进程已经退出。
- **疑似停滞**：AutoClaw 索引仍在运行，但本轮缺少执行进程证据，或存活进程超过 5 分钟没有新会话事件。显示静默时长；长工具调用也可能出现这个状态，因此不等同于已经中断。出现真实新事件后自动恢复。
- 读取失败、采集过期或无法确认时降为未知状态，计时冻结；有效身份的 Codex 对话保留「待确认」显示。缺少起点时显示“未提供开始时间”，详情说明是日志缺失、读取受限还是日志尚未回溯到起点；不拿会话创建时间冒充本轮开始。
- WorkBuddy 和 AutoClaw 的详细错误仅转换为简短原因：限流/配额、DNS、连接失败、超时、认证、上下文限制等。日志未说明具体原因时明确标注，不猜测触发者；较新的用户消息不继承上一轮的旧错误。
- AutoClaw 续建会话锁不会重置任务开始时间，也不算新的任务进展。只读取 `~/.openclaw-autoclaw`，与独立 OpenClaw 数据隔离。

## 窗口权限

上述本地结构化会话读取不需要屏幕录制权限。其他应用的窗口识别需要在“系统设置 → 隐私与安全性 → 辅助功能”中开启“任务雷达”。浮窗底部常驻「辅助功能」检查栏：点击「查询」后原位显示结果，实际读到窗口显示绿色「已生效」，未获授权显示红色「未授权」，系统报告已授权但没有读到可验证窗口显示红色「未确认」。原因保留在悬停提示中，不弹出需要关闭的结果窗口。右侧跳转按钮直接打开系统辅助功能设置；从此入口授权后会自动重新查询。重建导致签名变化时，旧授权可能失效；若开关已开启仍显示未授权，应移除旧条目，再添加当前安装版本。

**1.5.1 自助修复**：菜单「辅助功能自助修复…」始终可打开，底部查询失败时也显示「修复」。独立窗口可随时关闭，分别显示窗口实际读取与输入恢复组件状态；查询结果原位红绿反馈。组件“已响应”只说明组件运行与系统授权查询成功，不代表已验证某个会话输入框。窗口同时显示当前路径/版本与正式路径，避免给 build 副本授权。

如果系统开关已经开启但仍失败，按窗口指引：打开辅助功能设置 → 选旧「任务雷达」点减号 → 加号添加 `/Applications/任务雷达.app` → 开启并完成系统认证 → 回应用点「重启正式版并查询」。窗口提供直达设置、Finder定位正式版、复制路径和重启按钮；无需每次找 Agent 操作。重启只打开固定正式路径，等旧实例退出；失败记在本机 `permission-restart.log`。不会自动 reset TCC、操作系统权限数据库或改变证书信任。

修复窗口打开期间临时暂停自动恢复调度，采集继续，持久自动发送开关不变；关闭窗口后恢复原设置并清除旧排队。普通启动不弹修复窗，只有明确执行“重启正式版并查询”才在新进程自动打开并查询。实际授权仍以新进程的窗口读取/组件结果为准，不承诺证书签名永不失效。

日常采集不切换应用。开启「自动继续意外中断」后，符合下述条件的新中断会弹出提示，再切换到对应会话并发送固定续写文字。可随时在菜单关闭或暂停监控。

## 运行模式与点击恢复（1.6）

菜单「运行模式与提示词…」提供两种模式。升级默认协作模式，保留原提示词与会话配置；切模式不会自行开启自动发送，也不会启动历史已完成的项目。

- **协作模式**：雷达观察到真实「进行中 → 本轮完成」后，按会话排队弹出“这个项目已完结，请验收”。提醒保留每个未读会话的最新状态，点「知道了」查看下一条；左下角数字表示当前卡片之外的未读会话数，也包含定位或恢复失败。这里的“完结”来自本轮结束事件，项目是否通过验收仍由你判断。
- **狂暴模式**：选择「监督某软件的全部对话」或逐条标记会话，再开启自动发送。雷达对新鲜、可核验的本轮明确结束或可恢复意外中断直接续接，不再读取回答正文并调用本机模型判断完成程度。每条会话独立计数：第 N、2N 次发送可编辑的特别提示词，其余发送普通优化提示词；N 和两种文字均可设置，成功点击发送才计数，重启后延续。每轮只尝试一次，发送前核验身份、来源、轮次、唯一输入框和草稿回读。主动停止、等待确认、未知状态、无法定位或需人工解决的限制只提醒。非限流意外中断发现后 1 秒排定，以 10 秒内发送为目标；权限、用户输入、限流、应用响应及多会话串行可能阻碍。无总轮数上限；取消选择、暂停或切模式取消待发送动作。
- **历史会话**：只有狂暴模式、自动发送开启，且明确选择监督范围后，设置中的「启动已标记的完成会话」才会把旧轮次加入续接队列。仅启动软件或切换模式不会批量发送。旧单会话提示词保留在右键编辑入口，当前模式不执行这些旧跟催规则。
- **点击旋转图标**：中断提醒左上角图标可恢复该条会话，Grok 使用专用续接文字，其余软件发送「刚才中断了，请继续」；完成待验收提醒的同一个图标可手动切回该对话并发送一次「请继续」，即使自动发送总开关关闭也可单次操作。悬停高亮，执行时旋转并禁用，避免连击重复。点击不修改全局开关，也不退出或重启整个 AI 应用。发送前核验原会话、原轮次、明确完成/中断状态、唯一输入框与发送按钮；状态变化、主动停止、等待确认、已尝试本轮或移除会话时拒绝并说明原因。完成提醒宽 232 点，带副标题的样本为 232 × 158 点，其他提醒宽 240 点；标题区域可拖动，右下保留「知道了」。弹窗和音效开关位于「设置 → 运行 → 提醒」，修改后保存；关闭弹窗仍可保留完成音效。
- 默认自动发送关闭时只提醒。暂停、关闭自动发送、修改模式或提示词、移除会话会取消旧排队动作；不支持可靠输入的应用仍显示具体限制。未写入的权限/焦点错误可在解决后再次点击；已经输入或点击发送的同一轮不重发。
- 实际输入前再次检查会话身份、项目、轮次、唯一输入框与发送按钮；按授权覆盖草稿并回读文字，再单次发送。WorkBuddy 使用输入框边界建立真实编辑焦点。应用不会通过最小化、关闭或重新启动抢前台。会话切换、输入回读失败或出现运行状态会停止动作。
- 点击发送后继续核验新轮次，快速完成的下一轮也可作为回执；未观察到新轮次会明确显示未确认，不将输入框清空当作模型已经恢复。
- 菜单「查询 AI 监督状态」和底部「查询」原位反馈权限与监督状态，不打开诊断对话框。预览提醒不会发送。所有监控、提示词与防重复记录均留在本机。

ZCode 的公开链接只打开工作区；恢复使用本机任务索引核验任务 ID，再从桌面搜索唯一完整标题与项目并回读当前顶部身份。同项目同名任务、搜索结果不唯一、输入框不可读或用户正在操作时只提醒，不发送。旧的已完成轮次仍须在设置中显式启动。

会话定位分为本地身份、导航结果、顶部标题/项目、聊天输入框与发送控件几步。1.8.2 起会分别报告同名冲突、项目重名、搜索入口不可用、搜索无结果、侧栏未展开及顶部身份不一致；尚未输入时的暂时加载失败最多重试三次，身份冲突与搜索输入变化直接停止。ZCode 支持中英文原生搜索，使用真实粘贴触发搜索并恢复剪贴板；折叠侧栏时按相邻的项目按钮与顶部一级标题核验。AutoClaw 支持新版天/周/月/年标签，唯一侧栏展开入口或唯一「展示更多」可自动展开；目标编辑面板的交付物/完成标准输入框不作为聊天输入框。内部 subagent、cron 和 evolution-check 在最近会话限额之前排除。

发送桥支持 Codex、WorkBuddy 两版、AutoClaw、Grok、Qoder、Qoder CN 和符合上述唯一定位条件的 ZCode；实际缺少身份、轮次或控件时仍拒绝。Grok 自动续接仍须桌面标题、项目选择器和本地 session ID 联合核验；应用自身错误或重复身份会停止恢复。Qoder 两版分开读取自己的数据库并核对自己的页面 URL；工作区显示名由该会话的 workspace ID 查得，不要求它等于目录名。

狂暴模式不再依赖 Ollama 或回答内容判断；仍需明确的本轮结束/意外中断证据和发送前会话核验，未知状态只提醒。

**1.5.2 修正**：自动优化发出后，新轮即使瞬间因服务端错误中断、来不及观察“进行中”，也能按原有中断规则恢复；主动停止或原因不明确仍只提醒。升级保留旧发送日志中尚存在的防重记录，避免详情清理后重复尝试旧轮；不设每轮累积记录上限，新的可靠轮次按会话保留最新水位。

**1.5.1 实测**：专用 WorkBuddy AI 恢复会话已通过真实导航、非空输入覆盖与回读、发送及新一轮完成验证：本轮只发送一次「刚才中断了，请继续」，收到「恢复测试通过」。中断触发由隔离测试进程注入，未修改会话数据库；其他软件不能据此视为全部通过。WorkBuddy AI 精确侧栏匹配兼容实际观察的分钟/天后缀（如 `1m`、`47m`、`2d`），仍须完整唯一标题和顶部会话核验。

输入前保留硬件键鼠空闲至少两秒的保护，使用 macOS HID system state 时钟；读取失败按正在活动处理。该时钟不承诺覆盖所有远程合成事件，锁屏、前台和唯一目标核验仍独立执行。

**系统权限与实测范围**：安装版及其子进程需通过辅助功能实查。构建只使用已有有效签名身份；缺失时明确失败，不静默降为 ad-hoc。仅开发测试可显式设置 `AGENT_RADAR_ALLOW_ADHOC=1`；不会创建或信任新证书。测试通过不代表所有真实应用已完成发送验收，当前证据与限制见 [验证记录](docs/verification.md)。

## 数据与性能

所有处理均在本机进行，无外部 AI API 调用，不上传聊天、不读取认证配置。会话数据库以 SQLite 只读方式打开；需要日志补充时只解析有界数据。AutoClaw 缺少标题时从有界开头提取首条用户请求作为短标题，剔除系统提醒和附件路径；不保留工具参数、回复正文，不另存聊天记录。

每约 1 秒采样，采集耗时会影响实际周期。Codex 与 Claude 合计最多 50 条近期主会话，ZCode、两个 WorkBuddy、AutoClaw 各最多 40 条。AutoClaw 最多读取 16 个代理目录、每个索引 8 MB、会话头 128 KB、尾部 2 MB；WorkBuddy 两个版本各段日志尾部最多 2 MB，缓存只保留生命周期时间和归类后的错误，不保留原始错误字符串。窗口扫描有超时和节点上限。读取失败会在后台诊断中说明；有效身份的 Codex 保留「待确认」，其余无法识别的条目留在后台，不会把旧的“运行中”一直当成实时结果。

窗口位置、透明度、磨砂档位、自动继续开关及兼容的旧版标签/置顶数据存在应用自己的 UserDefaults；`~/Library/Application Support/AgentRadar/health.json` 只保存应用名、计数与健康/监督状态，不保存聊天正文和项目路径。`continuation-attempts.json` 仅保存会话/轮次标识的 SHA-256 与尝试时间，保留最多 256 条、7 天，用于重启防重与冷却。

会话移除清单使用应用自己的 `removedSessions.v1` 设置，保存匹配标识、应用名、短标题和移除时间，供恢复菜单使用；窗口回退匹配标识可能包含项目路径。不会保存聊天正文，也不会写入其他 AI 应用的历史记录。

自动发现只在自己的 `autoDiscoveredAIBundles.v1` 设置中记住应用 Bundle ID。未知应用窗口的扫描同样计入每轮 3.2 秒预算，每个候选最多 0.25 秒。Cline 最多读取 40 条主会话；查询只投影标题、路径、状态、轮次时间和归类用的错误字段，不读取 `prompt`、回复正文、配置凭据或完整事件包。

该检查使用源码适配器和正式安装版已有的 AX/PyObjC 运行库。目标需已在当前窗口打开；其他会话会报告身份不匹配。`ready` 仅表示控件核验通过，`already_running` 表示当前仍在运行，两者均不证明真实发送或恢复成功。

`link_test.sh` 对本机已接入软件（含 Codex、Claude Code、ZCode、WorkBuddy 两版、AutoClaw、Qoder 两版、Grok、Cline）做只读真实链路测试：数据源 → 采集行 → 跳转目标 → 系统注册的处理应用逐段核对；应用未安装或没有当前会话记为说明而非失败。这是数据与路由注册核对，不等同于所有软件的精确对话跳转或真实发送验收。

构建产物为 `build/任务雷达.app`，使用本机已有有效 AgentRadar Local 签名；缺少该身份时默认停止构建。源码在 `Sources/`，数据适配器在 `collector/`。各 AI 应用升级后本地数据格式可能变化；错误和未知状态不会被当作成功。
