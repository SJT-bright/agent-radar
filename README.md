# 任务雷达

本地 macOS 与 Windows 原生悬浮任务窗。当前版本 **1.9.1**，包含按应用选择提醒，源码采用 MIT 许可。

- [macOS arm64 下载](https://github.com/SJT-bright/agent-radar/releases/tag/v1.9.1)
- [Windows x64 安装包、便携包与使用说明](Windows/README.md)

显示 AI 应用、工作文件夹、当前对话、本轮时长和中断状态。界面包含胶囊、分组列表、提醒队列、设置、监督范围、置顶和移除。默认协作模式，自动发送默认关闭。

## OpenClaw 持续关照

在指定会话菜单中开启持续关照，并显式开启自动发送。关注后续的新鲜轮次：发现可核验的意外中断后，通过本地网关恢复该条原会话；本轮完成只提醒「这个项目已完结，请验收」。主动停止、等待确认、身份不明、认证或上下文限制保持停止或只提醒。

每条会话每小时最多自动恢复 3 次，计数持久保存，重启不会清零。后台子任务须逐条选择，定时任务不会批量启动。持续关照的会话跨日期保留展示；即使没有桌面窗口，也可从本地生命周期记录核验。关闭关照或移除会话取消旧排队。

OpenClaw 使用原会话 ID、会话键和同一 run ID 的生命周期记录，恢复走官方本地客户端及 loopback 网关。过程不切换窗口、不抢键盘、不重启整个 AI 应用。持续关照能恢复对话执行，不能修复底层模型服务的网络连接、认证或配额问题。Windows 支持原生入口与明确配置的本机 WSL，详见 [Windows 说明](Windows/README.md)。

## 严格顺序队列

手动请求和自动恢复统一按入队顺序操作。定位重试保留原位；发送后继续占用操作通道，直到确认原会话的新轮次或明确报告 30 秒超时。超时后只读观察，不重复发送该轮，也不插队。

暂停、关闭、切模式、修改执行提示词、撤销监督、移除会话或身份变化取消旧操作。已有草稿只在明确恢复请求内覆盖，写入后回读；发送前再次核验本轮身份和唯一发送控件。不能核验时保持待确认。

## 识别与提醒

| 数据源 | 用途 |
| --- | --- |
| 只读数据库与生命周期日志 | 会话 ID、工作区、轮次开始/结束、主动停止与错误类别 |
| macOS Accessibility / Windows UI Automation | 当前窗口、输入区、按钮和实际可用状态 |
| Claude 可选生命周期入口 | 明确的本轮开始、结束、等待和中断元数据 |
| OpenClaw 本地网关 | 原会话恢复与匹配新 run ID 的确认 |

不拿文件修改时间或应用进程存在冒充会话运行。Codex 长日志分块回溯，每块最多 8 MiB，最多缓存 4096 条结构元数据。无法确认状态时保留已核验身份的「待确认」，不算活动、不触发自动发送或目录冲突。

采集器不读取凭据，不上传聊天，不保留对话正文。外部数据库设限、只读并容错；慢采集源独立降为待确认。操作回执只记录散列 ID、阶段、耗时和固定错误类别。恢复客户端使用用户原有的本地登录配置。

同目录的跨软件活动会话可提示文件冲突。完成提醒和中断提醒按原会话保留最新一项，支持逐项确认、全部确认、跳转、恢复一次与音效。软件专属、通用、特别和限流提示词分别保存；超过 2000 字符保留全文并阻止保存。

在「设置 → 提醒」中，可分别设置弹窗、音效，并勾选需要提醒的应用。支持搜索、全选和全不选；点击保存后立即生效，重启后保留。全选包含以后新增的应用；仅勾选部分应用时，新应用默认不提醒，暂时未运行的已选应用仍保留选择。取消某个应用会收起它当前及排队中的提醒，重新勾选不会补发旧完成提醒。

提醒应用范围只控制弹窗与音效，监督、持续关照和自动发送分别按原有授权执行。同目录提醒涉及任一已选应用时仍可提示。旧版没有应用选择设置时保持全部应用提醒。1.9.1 的测试、实际点击与正式安装记录见 [应用提醒选择验收](docs/reminder-apps-1.9.1.md)。

## 两个平台

macOS 使用 SwiftUI/AppKit，正式入口 `/Applications/任务雷达.app`，要求 macOS 13+、Apple Silicon。窗口与输入组件在菜单「查询」分别实查；正式更新使用已有有效签名身份，不自动重置 TCC 或改变证书信任。

Windows 使用 WPF、原生 UI Automation 和冻结的 Python 采集组件，支持 Windows 10/11 x64。安装在当前用户目录，数据放在 `%APPDATA%\AgentRadar`。包内含运行时，不要求管理员权限、Python 或 .NET 预安装。

字体和毛玻璃效果随系统变化。具体 AI 软件的新版本可能改变本地格式及输入控件；不能证明原会话或唯一发送按钮时拒绝发送。Windows 外部 AI 应用的真实发送须在安装对应软件的设备继续验收，CI 界面与采集器测试不代表外部消息已经送达。

## 构建

```sh
./scripts/build.sh
./scripts/test.sh
```

Mac 正式构建要求本机已存在有效 `AgentRadar Local`。仅开发环境可显式选择 ad-hoc，不用于覆盖正式版。

```powershell
python -m pip install pyinstaller==6.16.0
dotnet run --project Windows/AgentRadar.Core.Tests -c Release
./Windows/build.ps1
```

Windows 构建需要 .NET 10 SDK、Python 3.12 与 Inno Setup。相关实现位于 `Windows/`；两端共享适配器位于 `collector/`、恢复协议位于 `supervisor/`。
